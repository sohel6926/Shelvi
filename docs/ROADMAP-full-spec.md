# పూర్తి ప్లాన్ / Full-spec roadmap (owner decision, 18 Nov 2026)

ఓనర్ నిర్ణయం: 6 frozen spec PDFs మొత్తం + Smart CRM లాంటి lead-to-revenue భాగం — అన్నీ పూర్తయ్యాకే live. ఒక్కో module వరుసగా పూర్తి చేయాలి.
Owner decision: build the whole of the 6 frozen spec PDFs plus a Smart-CRM-style lead-to-revenue layer; go live only after all of it; finish one module at a time, in this order.

## Order
1. **Leads + pipeline** — all leads in one inbox, auto-assign to staff (rules / round-robin), Kanban stages, follow-up reminders + 15-min TAT with escalation, CSV import, HOT/WARM/COLD score, team chat on a lead.
   Needs outside accounts (owner): WhatsApp Business API number (auto WhatsApp, bulk), telephony provider (auto dialer, call recording), Meta / Google / JustDial / IndiaMART lead access. Build with a manual fallback until each is connected.
2. **Recipe/BOM + batch/expiry** — ingredients per dish, sub-recipes, yield, plate cost; UOM master; batch/lot, expiry, FEFO for packed products.
3. **Purchases: PR -> PO -> GRN -> three-way match + approvals** (spec PDF 06, TWF).
4. **Accounting ledger + roles** — double-entry, chart of accounts, period close/lock, 17 roles, approval limits.
Then the rest of the spec: Company -> Brand -> Branch -> Kitchen -> Store hierarchy, packing/dispatch, food-safety matrix, remaining screens and reports.

## Rule for every module
Spec pages first -> data model + rules -> server callables + tests -> web -> phone -> checker pass -> update requirements-checklist.md and CODE-MAP.md. A module is done only when its tests pass and it has been clicked through in test mode.
